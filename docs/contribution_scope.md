# 계정 크롤링과 모델 개발의 기여 구분

계정 데이터 크롤링은 팀원이 담당했습니다. 본인은 수집 이후 전처리·정규화·모델 학습을 맡고, PM으로 프로젝트 일정 조율과 핵심 기능 제안을 담당했습니다.

## 본인 담당

수집된 프로필 수치를 모델 입력으로 정리하고 라벨·특성 열을 맞췄습니다. 기준 플랫폼에서 적합한 scaler를 사용해 플랫폼 간 특성 척도를 맞추는 실험과 분류 모델 학습을 진행했습니다. Instagram에서 학습해 X에 적용하는 방향, 반대 방향, 추가 봇 데이터를 결합하는 재학습 경로를 구분합니다.

각 경로의 선택 특성과 scaler가 달라 전처리 결과를 임의로 교환하지 않습니다. 모델은 Random Forest·Gradient Boosting·LightGBM·XGBoost와 soft voting 등을 비교하는 코드로 구성됩니다.

## 팀원 담당 자료

`notebooks/collection`에는 라벨 ID로 사용자명을 조회하고 로그인 후 프로필을 수집하는 노트북을 보관했습니다. 이 수집 로직은 팀원 기여로 표시하고, 본인이 크롤러까지 구현한 것으로 설명하지 않습니다. 원본 계정 목록과 로그인 인증 정보는 공개 소스와 분리합니다.

## 평가 조건

같은 플랫폼 내부 검증과 다른 플랫폼 외부 평가는 모집단이 다릅니다. 추가 봇 데이터 모델의 저장 내부 검증 accuracy는 79.33%이며 확률 임계값 0.6을 사용합니다. Instagram 외부 평가는 69.68%이며 기본 predict를 사용합니다. 표본과 결정 조건이 달라 이를 같은 조건의 전후 성능 변화로 해석하지 않습니다.

일부 과거 전처리는 train·test 파일을 합쳐 표준화한 뒤 재분할합니다. 독립 최종 테스트를 보존한 결과와 구분해야 하며, scaler의 적합 범위와 동일 계정 중복 여부는 재현 시 확인할 사항입니다.

## 서비스 구현 범위

현재 자료는 모델 연구이며 온라인 분류 서비스의 배포 완료를 뜻하지 않습니다. 서비스 아키텍처 그림은 모델 연구를 단일 계정 추론으로 확장하는 설계안입니다.
