# 플랫폼 간 가짜 계정 분류

크롤링은 팀원이 담당하고, 저는 이후 전처리·정규화·모델 학습을 맡았습니다. PM으로 프로젝트 일정 조율과 핵심 기능 제안도 담당했습니다.

## 문제와 실험

Instagram과 X의 프로필 특성으로 가짜 계정을 분류하고 플랫폼 간 일반화 성능을 비교합니다. 한 플랫폼에서 학습한 모델을 다른 플랫폼에 적용하는 문제를 다룹니다.

## 역할 분담

| 참여자 | 담당 범위 |
|---|---|
| 본인 | PM · 수집 이후 전처리 · 정규화 · 모델 학습 |
| 팀원 | 계정 데이터 크롤링 |

## 본인 담당 흐름

수집 데이터 인계 → 라벨·특성 정리 → 기준 플랫폼 scaler를 통한 정규화 → 분류 모델 학습 → 내부·외부 플랫폼 평가로 이어집니다. Instagram → X, X → Instagram, 추가 봇 데이터 재학습의 경로를 구분합니다.

## 저장 결과의 해석

추가 봇 데이터 모델의 내부 검증 accuracy는 79.33% (임계값 0.6), Instagram 외부 평가는 69.68% (기본 predict)입니다. 서로 다른 모집단과 결정 조건이므로 같은 조건의 개선율로 표현하지 않습니다.

일부 전처리의 train·test 결합과 표준화 시점은 재현 시 검토할 항목입니다. 현재 자료는 모델 연구이며 실제 온라인 분류 서비스 배포와는 구분합니다.
